## 🚀 Roadmap: 60 Days of Python (Java Developer Edition)

### Fase 1: Transição Java -> Python (Dias 2-10)
*Foco: Sintática, Tipagem Dinâmica vs Estática e Gerenciamento de Ambiente.*

- [ ] **Dia 2:** Estruturas de Dados Dinâmicas: Lists, Dicts, Sets e Tuplas (e quando usar cada uma).
- [ ] **Dia 3:** List Comprehensions e Dict Comprehensions (o "jeito Python" de fazer streams/filtros).
- [ ] **Dia 4:** Funções: *Args, **Kwargs e Type Hinting (essencial para quem vem do Java).
- [ ] **Dia 5:** Virtual Environments: Venv, Poetry e gerenciamento de dependências.
- [ ] **Dia 6:** Programação Orientada a Objetos (POO): Classes, Mixins e o "Self" vs "This".
- [ ] **Dia 7:** Tratamento de Erros: Try/Except/Finally vs o modelo de Exceptions do Java.
- [ ] **Dia 8:** Módulos e Packages: Como o Python organiza o classpath.
- [ ] **Dia 9:** Manipulação de Arquivos e Context Managers (o comando with).
- [ ] **Dia 10:** **Laboratório 1:** Criar um script CLI que lê um JSON e gera um relatório formatado.

### Fase 2: Python Intermediário e Ferramental (Dias 11-25)
*Foco: O que acontece por "baixo do capô".*

- [ ] **Dia 11:** Decorators: Entendendo as anotações (equivalente aos @Annotations do Spring).
- [ ] **Dia 12:** Iteradores e Geradores: Economia de memória em grandes volumes de dados.
- [ ] **Dia 13:** Dunder Methods (Magic Methods): `__init__`, `__str__`, `__repr__`, `__call__`.
- [ ] **Dia 14:** Multithreading vs Multiprocessing: O impacto do GIL (Global Interpreter Lock).
- [ ] **Dia 15:** Programação Assíncrona (AsyncIO): O modelo Event Loop.
- [ ] **Dia 16-20:** Testes Unitários: PyTest (fixtures, mocks e parametrização).
- [ ] **Dia 21-25:** **Projeto Curto:** Criar um sistema de log assíncrono que grava em múltiplos destinos.

### Fase 3: Ecossistema de Microserviços (Dias 26-40)
*Foco: Substituir o Spring Boot/Jakarta EE.*

- [ ] **Dia 26:** FastAPI: O "novo padrão" para APIs rápidas e tipadas.
- [ ] **Dia 27:** Pydantic: Validação de dados e Data Transfer Objects (DTOs).
- [ ] **Dia 28:** SQLAlchemy ou SQLModel: O "Hibernate" do mundo Python.
- [ ] **Dia 29:** Migrations com Alembic.
- [ ] **Dia 30:** Dependency Injection em Python (fastapi-users, dependency-injector).
- [ ] **Dia 31-35:** Dockerizando aplicações Python (otimização de imagens e camadas).
- [ ] **Dia 36-40:** **Laboratório 2:** Criar o "esqueleto" do microserviço que você planeja migrar.

### Fase 4: IA, Agentes e Automação (Dias 41-55)
*Foco: TigerAI e Integrações.*

- [ ] **Dia 41:** Integração com APIs de LLM (OpenAI, Gemini SDK).
- [ ] **Dia 42:** LangChain ou CrewAI: Orquestração de agentes.
- [ ] **Dia 43:** MCP (Model Context Protocol): Criando servidores MCP em Python.
- [ ] **Dia 44:** Vetores de Banco de Dados: ChromaDB ou Pinecone com Python.
- [ ] **Dia 45-55:** Desenvolvimento intensivo dos sub-agentes do seu projeto TigerAI.

### Fase 5: Refino e Migração Final (Dias 56-60)
- [ ] **Dia 56:** Performance Tuning: Profiling de código Python.
- [ ] **Dia 57:** Segurança: Bandit e Safety para auditoria de código.
- [ ] **Dia 58:** CI/CD para Python: GitHub Actions e Linting (Ruff/Black).
- [ ] **Dia 59:** Finalização da migração do microserviço.
- [ ] **Dia 60:** Review Final e Retrospectiva.
